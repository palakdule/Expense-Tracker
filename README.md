# 💰 Expense Tracker

A simple and beginner-friendly **Expense Tracker** built using Python.

This project allows users to manage their income and expenses, organize expenses by category, view expense history, and check their current balance.

## ✨ Features

- 💵 Add Income
- 💸 Add Multiple Expenses
- 🏷️ Expense Categories
- 📅 Automatic Expense Date
- 📋 View All Expenses
- 📊 Expense Summary by Category
- 💰 Check Current Balance
- 💾 Store Data using JSON
- ✅ Input Validation

## 🛠️ Technologies Used

- Python
- JSON
- File Handling

## 📂 Project Structure

    Expense-Tracker/
    │
    ├── main.py
    ├── .gitignore
    └── data.json

> `data.json` stores expense data locally and is excluded from GitHub using `.gitignore`.

## ▶️ How to Run

1. Open the project folder.
2. Open the terminal in the project folder.
3. Run `python main.py`.
4. The Expense Tracker menu will appear.

### Main Menu

    ===== EXPENSE TRACKER =====
    1. Add Income
    2. Add Expense
    3. Check Balance
    4. View Expenses
    5. Expense Summary
    6. Exit
